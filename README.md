# Mała Nauka

Jedna aplikacja PWA z pięcioma niezależnie rozwijanymi modułami:

- Ortografia
- Matematyka
- Flagi
- Czytanie
- Angielski

## Struktura

- `/` — wspólna powłoka aplikacji, nawigacja, ustawienia, PWA, iPhone/safe-area, wspólne postępy
- `/ortografia/` — mechanika ortografii
- `/matematyka/` — mechanika matematyki
- `/flagi/` — mechanika flag
- `/czytanie/` — mechanika czytania
- `/angielski/` — mechanika angielskiego
- `/shared/` — wspólne komponenty i utilities

Repo powstało przez migrację projektu Mała Nauka ze starego repo `appka-policyjna-baza`. Stare repo pozostaje nietknięte jako backup podczas migracji.
